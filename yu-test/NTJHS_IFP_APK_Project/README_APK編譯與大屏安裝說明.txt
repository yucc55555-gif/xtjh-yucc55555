================================================================
新泰國中校園無聲廣播系統 - Android IFP 觸控大屏接收端 (APK) 說明
================================================================
1. 架構說明：
   - 本系統採「純線上網頁版（無伺服器）」雲端直連架構，學校無需自架任何伺服器主機。
   - 觸控大屏安裝 APK 後，【只要輸入班級即可執行，完全不須輸入伺服器 IP】。
2. 免裝 Android Studio 雲端自動編譯 APK：
   - 將本專案上傳至免費 GitHub 儲存庫，開啟上方 Actions 分頁即會自動執行 build-apk.yml 編譯出 app-debug.apk。
3. 隨身碟安裝至觸控大屏：
   - 將 APK 放入 USB 隨身碟並插入大屏，點擊安裝並允許「顯示在其他應用程式上層」。
   - 開啟 APP 後，只需輸入該教室「班級名稱」（例如：701、807、917 或 校史室）並點擊啟動即可常駐運作。
