一、選擇題 (共 94 分)
1.(　) 下列哪一組的兩個圖形必為相似形？
(A) 兩菱形
(B) 兩等腰梯形
(C) 兩長方形
(D) 兩等腰直角三角形
✓ 正解：(D) 兩等腰直角三角形
📌 核心觀念
多邊形與三角形的相似條件（AAA 相似與形狀固定性）。
📝 逐步詳細解析
多邊形相似必須同時滿足：① 對應角相等，② 對應邊成比例。
(A) 兩菱形： 四邊等長（邊長成比例），但內角不一定相等（例如一個內角為 60°、120°，另一個為 80°、100°），故不一定相似。
(B) 兩等腰梯形： 底角不一定相等，各邊比例亦不一定相同，故不一定相似。
(C) 兩長方形： 四個內角皆為 90°（對應角相等），但長寬比不一定相同（例如 $2 \times 3$ 與 $1 \times 5$），故不一定相似。
(D) 兩等腰直角三角形： 任何等腰直角三角形的三個內角固定為 45°、45°、90°。由 AAA 相似性質，任意兩個等腰直角三角形必為相似形。
🔍 選項分析
等腰直角三角形形狀固定，角度完全一致，故選 (D)。
2.(　) 在 $\triangle ABC$ 中，D、E 兩點各在 $\overline{AB}$、$\overline{AC}$ 上，則下列哪一個條件不能說明 $\overline{DE}$ 一定平行 $\overline{BC}$？
(A) $\overline{AD} : \overline{BD} = \overline{AE} : \overline{EC}$
(B) $\overline{AE} : \overline{AC} = \overline{AD} : \overline{AB}$
(C) $\overline{DE} : \overline{BC} = \overline{AD} : \overline{AB}$
(D) $\overline{AB} : \overline{BD} = \overline{AC} : \overline{EC}$
✓ 正解：(C) DE:BC = AD:AB
📌 核心觀念
平行線截比例線段定理之逆定理：僅有兩側截線段成比例能保證平行。
📝 逐步詳細解析
根據平行線截線段定理之逆定理：
在 $\triangle ABC$ 中，若直線截兩邊 $\overline{AB}$、$\overline{AC}$ 所得的「兩側截線段成比例」，則該直線必平行於第三邊 $\overline{BC}$。
• (A) $\overline{AD}:\overline{BD} = \overline{AE}:\overline{EC}$（上比下 $=$ 上比下，能證明平行）。
• (B) $\overline{AE}:\overline{AC} = \overline{AD}:\overline{AB}$（上比全 $=$ 上比全，能證明平行）。
• (D) $\overline{AB}:\overline{BD} = \overline{AC}:\overline{EC}$（全比下 $=$ 全比下，能證明平行）。
• (C) $\overline{DE}:\overline{BC} = \overline{AD}:\overline{AB}$： 涉及底邊比與一側邊長比，由於存在 SSA（兩邊及其中一邊的對角）不確定全等/相似的幾何構造（圓弧可截出兩個不同方向的點），無法唯一確定 $\angle ADE = \angle B$，因此不能保證 $\overline{DE} // \overline{BC}$。
🔍 選項分析
選項 (C) 屬於「底邊比」，不能反推平行，故選 (C)。
3.(　) 若 $x : z = 2 : 3$，$y : z = 8 : 3$，則下列敘述何者錯誤？
(A) $x : y : z = 2 : 8 : 3$
(B) $\frac{x}{2} = \frac{y}{8} = \frac{z}{3}$
(C) $2x = 8y = 3z$
(D) $x : 2 = y : 8 = z : 3$
✓ 正解：(C) 2x = 8y = 3z
📌 核心觀念
連比的求法、等比式性質與乘積關係式的轉化。
📝 逐步詳細解析
1. 求連比：兩已知比中 $z$ 的比值均為 3，因此 $x:y:z = 2:8:3$，(A) 正確。
2. 設參數：令 $\frac{x}{2} = \frac{y}{8} = \frac{z}{3} = k$ ($k \ne 0$)，(B) 正確。
3. 則 $x = 2k, y = 8k, z = 3k$。
4. 檢驗 (C)：$2x = 2(2k) = 4k$，$8y = 8(8k) = 64k$，$3z = 3(3k) = 9k$。
顯然 $4k \ne 64k \ne 9k$，因此 $2x = 8y = 3z$ 錯誤（正確應為 $12x = 3y = 8z$ 等形式）。
5. 檢驗 (D)：由比的定義，$x:2 = y:8 = z:3 = k:1$ 成立，(D) 正確。
🔍 選項分析
選項 (C) 的乘積式與連比顛倒，故選 (C)。
4.(　) 下列敘述何者不正確？
(A) 兩三角形相似，則對應邊成比例
(B) 兩多邊形相似，則對應角相等
(C) 對應邊成比例的兩三角形必相似
(D) 對應角相等的兩多邊形必相似
✓ 正解：(D) 對應角相等的兩多邊形必相似
📌 核心觀念
多邊形相似的充分與必要條件 vs 三角形相似性質（SSS、AAA）。
📝 逐步詳細解析
• (A) 正確：由相似多邊形定義，對應邊必成比例。
• (B) 正確：由相似多邊形定義，對應角必相等。
• (C) 正確：由 SSS 相似性質，兩三角形對應邊成比例則必相似。
• (D) 錯誤： 對於四邊形（含）以上的多邊形，僅對應角相等「不能」保證相似。
　反例：正方形與長方形，各內角皆為 90°（對應角皆相等），但邊長不成比例，兩者不相似。
🔍 選項分析
選項 (D) 忽略了多邊形尚需對應邊成比例，故選 (D)。
5.(　) 在 $\triangle ABC$ 與 $\triangle DEF$ 中，若 $\overline{AB} : \overline{DE} = \overline{BC} : \overline{DF}$，則再加上下列哪一個條件時，可得 $\triangle ABC$ 與 $\triangle DEF$ 為相似的三角形？
(A) $\angle B = \angle D$
(B) $\angle B = \angle E$
(C) $\angle A = \angle F$
(D) $\angle A = \angle D$
✓ 正解：(A) ∠B = ∠D
📌 核心觀念
SAS 相似性質：兩組對應邊成比例，且其「夾角」相等。
📝 逐步詳細解析
觀察題目給定的兩組比例邊：
在 $\triangle ABC$ 中，兩邊為 $\overline{AB}$ 與 $\overline{BC}$，它們的夾角為 $\angle B$。
在 $\triangle DEF$ 中，對應兩邊為 $\overline{DE}$ 與 $\overline{DF}$，它們的夾角為 $\angle D$。
根據 SAS 相似性質，必須滿足「夾角相等」，即 $\angle B = \angle D$。
當 $\angle B = \angle D$ 時，$\triangle ABC \sim \triangle EDF$。
🔍 選項分析
對應邊的夾角分別是 $\angle B$ 與 $\angle D$，故需條件 $\angle B = \angle D$，選 (A)。
6.(　) 如圖(一)，$L_1 // L_2 // L_3$。若 $\overline{AC} = \frac{8}{5}\overline{BC}$，且 $\overline{CF} = 8$，$\overline{AD} = 20$，則 $\overline{BE} =$ ？
🔍 點擊圖片可放大檢視：圖(一)：三平行線 L1 // L2 // L3 截兩直線
(A) $\frac{21}{2}$
(B) $\frac{31}{2}$
(C) 14
(D) 28
✓ 正解：(B) 31/2
📌 核心觀念
平行線截比例線段與梯形分比長度公式。
📝 逐步詳細解析
1. 由 $\overline{AC} = \frac{8}{5}\overline{BC}$：
$\overline{AB} = \overline{AC} - \overline{BC} = \frac{8}{5}\overline{BC} - \overline{BC} = \frac{3}{5}\overline{BC}$。
因此 $\overline{AB} : \overline{BC} = 3 : 5$。
2. 觀察四邊形 ADFC 為梯形，$\overline{AD} // \overline{BE} // \overline{CF}$，其中 $\overline{AD} = 20$，$\overline{CF} = 8$：
利用內分比公式（交叉乘積法）：
$\overline{BE} = \frac{\overline{AB} \times \overline{CF} + \overline{BC} \times \overline{AD}}{\overline{AB} + \overline{BC}}$。
代入比值 $3 : 5$：
$\overline{BE} = \frac{3 \times 8 + 5 \times 20}{3 + 5} = \frac{24 + 100}{8} = \frac{124}{8} = \frac{31}{2}$。
🔍 選項分析
計算得 $\overline{BE} = \frac{31}{2}$，答案選 (B)。

🔍 點擊圖片可放大檢視：圖(二)：柏儀在線段 AB 上的尺規作圖痕跡
(A) 22.5
(B) 30
(C) 37.5
(D) 45
✓ 正解：(C) 37.5
📌 核心觀念
尺規作圖（平行線法截比例線段）與線段比例求解。

觀察圖(二)作圖痕跡：
1. 從 A 點作一射線，在射線上依序截取等長線段，標示出點 H 與點 K。

8.(　) 如圖(三)，四邊形 ABCD 中，$\overline{BD}$ 平分 $\angle CDA$。若 $\overline{AD} = 16$，$\overline{BD} = 24$，$\overline{CD} = 36$。若 $\angle ADC = 58^\circ$，則 $\angle ABC =$ ？
🔍 點擊圖片可放大檢視：圖(三)：四邊形 ABCD 與角平分線 BD
(A) $151^\circ$
(B) $152^\circ$
(C) $153^\circ$
(D) $154^\circ$
✓ 正解：(A) 151°
📌 核心觀念
SAS 相似三角形判定與三角形內角和性質。
📝 逐步詳細解析
1. 因為 $\overline{BD}$ 平分 $\angle CDA$，且 $\angle ADC = 58^\circ$：
$\angle ADB = \angle BDC = \frac{58^\circ}{2} = 29^\circ$。
2. 檢驗 $\triangle ADB$ 與 $\triangle BDC$ 的夾邊比例：
$\frac{\overline{AD}}{\overline{BD}} = \frac{16}{24} = \frac{2}{3}$
$\frac{\overline{BD}}{\overline{CD}} = \frac{24}{36} = \frac{2}{3}$
得 $\frac{\overline{AD}}{\overline{BD}} = \frac{\overline{BD}}{\overline{CD}}$，且夾角 $\angle ADB = \angle BDC = 29^\circ$。
3. 根據 SAS 相似性質：$\triangle ADB \sim \triangle BDC$。
4. 對應角相等：$\angle ABD = \angle BCD$，$\angle CBD = \angle BAD$。
5. 在 $\triangle ABD$ 中，三內角和為 $180^\circ$：
$\angle BAD + \angle ABD = 180^\circ - \angle ADB = 180^\circ - 29^\circ = 151^\circ$。
6. 所求 $\angle ABC = \angle ABD + \angle CBD = \angle ABD + \angle BAD = 151^\circ$。
🔍 選項分析
計算得 $\angle ABC = 151^\circ$，故選 (A)。
9.(　) 已知甲、乙、丙三人的錢數比為 2 : 5 : 6。若丙分別給甲、乙兩人各 30 元後，甲、乙、丙的錢數比變為 3 : 6 : 4，則此三人共有多少元？
(A) 320
(B) 360
(C) 390
(D) 480
✓ 正解：(C) 390
📌 核心觀念
總量不變原則下的連比運算技巧。
📝 逐步詳細解析
因為錢只是在三人之間流動，所以三人的總錢數保持不變。
1. 原來三人的比例總份數：$2 + 5 + 6 = 13$ 份。
2. 後來三人的比例總份數：$3 + 6 + 4 = 13$ 份。
巧妙之處：兩時期的總份數皆恰為 13 份，代表各份量之「每份價值」完全相等！
3. 觀察甲的份數變化：從 2 份增加為 3 份，淨增加 1 份。
而甲增加的錢正是丙給他的 30 元，因此：
1 份 $= 30$ 元。
4. 三人總錢數 $= 13 \times 30 = 390$ 元。
🔍 選項分析
總金額為 390 元，答案選 (C)。
10.(　) 沛霏想要榨果汁，她有蘋果、芭樂、柳丁三種水果，且其顆數比為 16 : 9 : 10。沛霏榨完果汁後，蘋果、芭樂、柳丁的顆數比變為 4 : 3 : 2。已知沛霏榨果汁時沒有使用芭樂，若原有三種水果共 70 顆，請問後來剩下的水果還有幾顆？
(A) 54
(B) 56
(C) 58
(D) 60
✓ 正解：(A) 54
📌 核心觀念
不變量（芭樂顆數不變）在連比例問題中的應用。
📝 逐步詳細解析
1. 原有水果總數為 70 顆，總份數為 $16 + 9 + 10 = 35$ 份。
每份為 $70 \div 35 = 2$ 顆。
因此原有水果數量分別為：
• 蘋果：$16 \times 2 = 32$ 顆
• 芭樂：$9 \times 2 = 18$ 顆
• 柳丁：$10 \times 2 = 20$ 顆
2. 關鍵條件：榨果汁時沒有使用芭樂，因此芭樂顆數依然為 18 顆。
3. 榨完果汁後，剩下顆數比為 蘋果 : 芭樂 : 柳丁 $= 4 : 3 : 2$。
此時芭樂佔 3 份，對應實際數量 18 顆：
新比例每份 $= 18 \div 3 = 6$ 顆。
4. 剩下水果總顆數為新比例總份數 $\times 6$：
總份數 $= 4 + 3 + 2 = 9$ 份。
剩下水果總顆數 $= 9 \times 6 = 54$ 顆。
🔍 選項分析
剩下水果共 54 顆，故選 (A)。
11.(　) 設 $\triangle ABC$ 之三邊長各為 a、b、c，且各邊上的高分別為 $h_a : h_b : h_c$。若 $a : b = 3 : 5$，$b : c = 4 : 5$，則 $h_a : h_b : h_c =$ ？
(A) 3 : 4 : 5
(B) 12 : 20 : 25
(C) 20 : 15 : 12
(D) 25 : 15 : 12
✓ 正解：(D) 25 : 15 : 12
📌 核心觀念
三角形面積定值下，邊長與對應高成反比的連比求法。
📝 逐步詳細解析
1. 求三邊長連比 $a : b : c$：
$a : b = 3 : 5 = 12 : 20$
$b : c = 4 : 5 = 20 : 25$
得 $a : b : c = 12 : 20 : 25$。
2. 由三角形面積公式：$\text{面積} = \frac{1}{2}a h_a = \frac{1}{2}b h_b = \frac{1}{2}c h_c$。
因為面積為定值，所以各邊的高與邊長成反比：
$h_a : h_b : h_c = \frac{1}{a} : \frac{1}{b} : \frac{1}{c} = \frac{1}{12} : \frac{1}{20} : \frac{1}{25}$。
3. 取分母 12、20、25 的最小公倍數 300，同乘以 300 化為最簡整數比：
$h_a : h_b : h_c = \frac{300}{12} : \frac{300}{20} : \frac{300}{25} = 25 : 15 : 12$。
🔍 選項分析
高的連比為 25 : 15 : 12，故選 (D)。
12.(　) 如圖(四)，瑾竣想從一塊直角三角形玻璃，切割出一塊最大正方形玻璃，而且這塊正方形的兩個鄰邊恰好在直角三角形玻璃的兩股上，如附圖。若 $\triangle ABC$ 中，$\angle B = 90^\circ$，$\overline{AB} = 75$ 公分，$\overline{BC} = 50$ 公分，請問這塊正方形玻璃的面積是多少平方公分？
🔍 點擊圖片可放大檢視：圖(四)：直角三角形中內接正方形
(A) 625
(B) 729
(C) 900
(D) 1024
✓ 正解：(C) 900
📌 核心觀念
直角三角形內接正方形的相似三角形邊長比應用。
📝 逐步詳細解析
1. 設內接正方形邊長為 $x$ 公分。
2. 正方形兩鄰邊在直角三角形的兩股上，則頂部留下一個小直角三角形，其兩股長度分別為 $(75 - x)$ 與 $x$。
3. 頂部小三角形與原直角三角形 $\triangle ABC$ 為相似形（AA 相似）：
$\frac{75 - x}{75} = \frac{x}{50}$。
4. 約分化簡：
$\frac{75 - x}{3} = \frac{x}{2} \Rightarrow 2(75 - x) = 3x$。
$150 - 2x = 3x \Rightarrow 5x = 150 \Rightarrow x = 30$（公分）。
5. 正方形玻璃面積 $= x^2 = 30^2 = 900$ 平方公分。
🔍 選項分析
面積為 900 平方公分，答案選 (C)。
13.(　) 如圖(五)，平行四邊形 ABCD 中，F 是 $\overline{CD}$ 上的一點，且直線 AF 交 $\overline{BD}$ 於 G 點、交直線 BC 於 E 點。則下列哪一個選項中的兩個三角形不一定相似？
🔍 點擊圖片可放大檢視：圖(五)：平行四邊形 ABCD 與直線截線
(A) $\triangle ABG \sim \triangle FDG$
(B) $\triangle AFD \sim \triangle EAB$
(C) $\triangle FCE \sim \triangle FDG$
(D) $\triangle AGD \sim \triangle EGB$
✓ 正解：(C) △FCE ~ △FDG
📌 核心觀念
平行四邊形平行線對頂角、內錯角所構成的 AA 相似判別。
📝 逐步詳細解析
• (A) $\triangle ABG \sim \triangle FDG$：
　$\overline{AB} // \overline{CD} \Rightarrow \angle BAG = \angle DFG$（內錯角），$\angle AGB = \angle FGD$（對頂角），由 AA 相似成立。
• (B) $\triangle AFD \sim \triangle EAB$：
　平行四邊形對角相等 $\angle D = \angle B$；又 $\overline{AD} // \overline{BC} \Rightarrow \angle DAF = \angle AEB$（內錯角），由 AA 相似成立。
• (D) $\triangle AGD \sim \triangle EGB$：
　$\overline{AD} // \overline{BE} \Rightarrow \angle GAD = \angle GEB$（內錯角），$\angle AGD = \angle EGB$（對頂角），由 AA 相似成立。
• (C) $\triangle FCE$ 與 $\triangle FDG$：
　兩三角形頂點 F 處僅有對頂角相等（$\angle CFE = \angle DFG$），但邊長不成比例且其餘角無平行內錯角關係保證相等，故不一定相似。
🔍 選項分析
選項 (C) 無足夠條件保證相似，故選 (C)。
